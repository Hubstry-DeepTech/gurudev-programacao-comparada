## Princípios

1. **Conteúdo analítico é sempre aberto** — o que é monetizado é a forma de acessar, processar e visualizar
2. **Valor derivado não-diluidor** — spinoffs geram valor sem comprometer integridade científica
3. **Credibilidade acadêmica é o maior ativo** — sem ela, o modelo freemium não funciona
4. **Missão antes de receita** — a Programação Comparada existe para gerar conhecimento, não lucro
